# Operation Name and first Phase entry — test

## Operation Name

1. In Edit mode, select an Operation and open `?`.
2. Change Name and commit by tabbing/clicking outside the field.
3. Confirm the Operation card immediately shows the new name.
4. Export and reload; confirm the name persists.

## First item in a new Operation

1. Create an Operation through its `⋮` menu.
2. Select the new Operation.
3. In the Phases lane, confirm the Start → End empty state shows **Add first item**.
4. Select **+ Process Phase** or **+ Transfer**.
5. Choose the item in the existing picker.
6. Confirm the new item is rendered between Start and End.
7. Export and reload.

The Operation menu remains Operation-only. Phase choices are offered in the selected Operation's Phases lane.
